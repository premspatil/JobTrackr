# JobTrackr Frontend (React + Vite)

```bash
npm install
npm start        # http://localhost:3000
npm run build    # production build in dist/
```

The backend must be running on http://127.0.0.1:8000 (see the root `README.md`).
To use another backend URL, copy `.env.example` to `.env` and edit `VITE_API_URL`.
